**Daily leadership:** OMNISYNAPSE sets questions, removes duplication, challenges weak evidence and ranks recommendations. The human founder retains authority.

The council below is a **planned agent roster**, not a claim that distinct models/accounts are already running. Each active member should issue a structured mini-report (see `templates/SPECIALIST_REPORT.md`). Each source must include date, URL or internal record ID, an evidence classification and relevant FOX tool.

## Reporting protocol

Each cell supplies max **3 material signals**, not 20 headlines. For each: what changed, when, direct source link, signal quality, potential FOX application, rough cost/effort, potential cognitive benefit, caveat and recommended next experiment. Scores include an uncertainty penalty.

OMNISYNAPSE then:
1. Merges repeated findings and traces known history.
2. Requests opposing perspectives and independent evidence review.
3. Builds a shortlist with cross-platform benefits and material commercial upside.
4. Selects only the 3 best supported opportunities for the executive report; reports fewer if evidence is insufficient.
5. Opens approval requests only for actionable controlled experiments.
6. Archives tested outcomes and lessons in the shared memory graph with controlled retention.

## Why all professionals don't have to run an expensive model every day

Use signal-driven activation: light official data checks daily, deep specialist work only when a relevant change or a user project requires it. This reduces model costs, false discoveries, and redundant research. Independently test whether deeper expert consultation improves decisions before scaling.
