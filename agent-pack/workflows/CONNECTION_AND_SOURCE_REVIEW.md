# Connection/source verification

Check (a) authenticated access and minimum scopes, (b) service ownership and data controller, (c) provenance and permissions, (d) API contract and quotas, (e) observability, (f) incident/rollback capability. Assign status: UNCONFIGURED, UNCONNECTED, VERIFYING, CONNECTED, DEGRADED, REVOKED. A public URL response is not proof of authenticated API integration.

Only collect public evidence when allowed by source policy/terms. Do not bypass CAPTCHAs/login, harvest people data or copy competitor code in violation of rights. Prefer official documentation, official datasets, legal APIs and reputable reporting. Track when each source was accessed and relevant coverage/limitations. Separate fact, interpretation and proposed action.
